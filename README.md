# 🚀 CourseManager

**CourseManager** — müəllim və tələbələri idarə edən, ödənişləri avtomatik hesablayan və statistik məlumatları vizual şəkildə təqdim edən açıq mənbəli bir masaüstü tətbiqdir.  
Sadəcə yüklə və dərhal istifadə et. ⚡  

![Preview](https://github.com/yourusername/CourseManager/assets/preview.png)

---

## ✨ Əsas xüsusiyyətlər

- 🧑‍🎓 **Tələbə idarəetməsi** — yeni tələbə əlavə et, məlumatlarını redaktə et və aylıq borcunu avtomatik hesablamaq imkanı.  
- 👨‍🏫 **Müəllim paneli** — müəllimlər əlavə et, dərs cədvəlini və gəlirlərini izləyin.  
- 📊 **Statistik qrafiklər** — gəlir, iştirak və ümumi fəaliyyət üzrə real-time vizual analizlər.  
- 🏫 **Dərs modulu** — dərsləri yarat, idarə et və tələbə ilə əlaqələndir.  
- 💾 **SQLite inteqrasiyası** — yüngül, etibarlı və oflayn işləyən məlumat bazası.  

---

## 🧠 Texnoloji Stack

| Layer | Texnologiya |
|-------|--------------|
| 🖥️ Frontend | [SolidJS](https://www.solidjs.com/) |
| ⚙️ Backend | [Rust](https://www.rust-lang.org/) |
| 🧩 Framework | [Tauri](https://tauri.app/) |
| 🗄️ Database | [SQLite](https://www.sqlite.org/) |

**Niyə bu stack?**  
Rust + Tauri = ultra yüngül, təhlükəsiz və performanslı tətbiqlər.  
SolidJS = modern, reaktiv və yüksək sürətli UI təcrübəsi.
